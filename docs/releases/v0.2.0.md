第一版发出去之后在真实环境里跑了两天，这一版修的全是跑出来的问题，另外加了检查更新。

**修了什么**

- WorkBuddy 这类每轮都带工具的宿主：高档没有配按量付费模型时，以前整轮报「没有可用的模型」，现在自动降到有模型的档位。
- WorkBuddy 里说「生成图片」，以前会被它自带的收费出图工具接走，现在直接走你在 Switchboard 里配好的渠道，图在对话里显示，路径也给出来；它每轮另发的一份转述请求不再重复出图。
- 宿主塞进请求里的环境信息（带属性的提醒块、`<session>`、`<user_query>`）以前会污染记录摘录、媒体库标题、产物文件名，甚至让一句「生成图片」被当成长文本。现在全部剥掉，历史记录也清一次。
- ChatGPT 订阅出图改为明确传低档模型，不再继承你自己 Codex 配置里的模型（免费套餐常常用不了那一个）。
- 菜单栏图标左键点不出面板：面板真正拿到焦点之后才会因失焦收起。
- 关掉主窗口后点 Dock 图标叫不回来、Dock 菜单只剩「无可用的窗口」：已处理。
- 退出应用会把后台一起带走：后台改为交给系统托管，不随应用退出。
- 从访达、Dock 或开机自启拉起的后台找不到 `claude`、`codex`、`node`：启动时补全命令搜索路径。
- 窗口比后台先起来时，主题只剩两套：词表取不到会重试，兜底列表也补齐四套。

**新增**

- 设置里多了「后台服务」一行：运行多久、一键重启；连着的后台不是这个安装包里的那份时会提示并建议重启。
- 设置和「关于」里能检查更新：每天到 GitHub Releases 查一次，连不上就查 Gitee 镜像；有新版本通知一声，一键下载本平台的安装包。

**安装**

- 覆盖安装即可；首次打开新版后到设置里点一下「重启」，让后台换成新版。
- 安装包仍未签名：macOS 在「系统设置 → 隐私与安全性」里点「仍要打开」，Windows 在 SmartScreen 提示时点「更多信息 → 仍要运行」。

---

Two days of real use after the first release; this version fixes what came up, and adds an update check.

- Agents that send tools on every turn (WorkBuddy and the like) no longer fail with "no model available" when the high tier has no pay-as-you-go model: the request steps down to a tier that has one.
- Saying "generate an image" in WorkBuddy now goes to your Switchboard image lane instead of the host's paid image tool; the image shows inline with its path. Host-injected context blocks no longer pollute call excerpts, media titles or file names.
- Menu bar click now opens the popover reliably; the main window comes back from the Dock; the backend survives quitting the app and can find `claude`, `codex` and `node` when launched from Finder or at login.
- New: a backend service row in Settings (uptime, restart, mismatch warning) and an update check against GitHub Releases (Gitee mirror as fallback) with a one-click download.

Installers remain unsigned; see the [README](https://github.com/imoling/iml-switchboard/blob/main/README.en.md#install).
