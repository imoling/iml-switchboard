功能版：应用级分派补齐生图与生视频、支持 Antigravity 一键接入与添加自定义应用、视频工具支持多参考图与首尾帧、配置改动自动刷新生效。

**新功能**

- 应用级生图、生视频顺序与自定义应用：「应用」页新增 **Antigravity**（自动读写 `~/.gemini/config/mcp_config.json`，支持一键接入、断开与启动时自动同步最新路径）和右上角「添加应用」，给任意支持工具协议的应用生成专属配置、独立启停和调用统计。每个应用的「档位候选」在低/中/高三档之外，新增「生图」和「生视频」顺序，可单独排或改回跟全局；停用后的应用发来的派活请求会被直接拒绝。
- 参考图生成视频：`generate_video` 新增 `image_paths`（多张参考图，兼容单张 `image_path`）、`last_image_path`（尾帧）、`size`、`out_dir` 参数。火山方舟按传参自动区分单图首帧（`first_frame`）、首尾帧（`first_frame` + `last_frame`）和多图参考（`reference_image`）；Agnes 支持首帧与尾帧；OpenRouter 与 OpenAI 兼容接口支持透传参考图。
- 配置改动自动刷新：`config.yaml` 被外部修改时后台自动按修改时间热加载；长驻的工具进程订阅后台事件流，在账号或档位配置变更、后台重启重连后自动刷新可用媒体型号说明并通知应用更新工具列表。

**修复**

- 生图与生视频严格遵守手排表：调用方传 `tier: "default"` 时不再绕过手排顺序与智能分派；传 `tier: "best"` / `"cheap"` / `"free"` 时，仅在该档位对应型号本身可用时提到最前，不可用时回退到手排第一顺位，不再把界面里放在「不用」里的模型调出来。
- 修复只出图出视频的服务（如火山方舟）没有文字型号时，接口返回 `models: null` 导致「模型」页打开档位弹窗报错的问题。

**测试**

- 新增覆盖：媒体 `default` / `best` 档位与手排表回退、应用级媒体顺序覆盖与停用拦截、火山方舟单图/首尾帧/多参考图请求体、Antigravity 一键接入与路径同步、自定义应用增删改、`config.yaml` 热加载、纯媒体账号视图。

0.9.0 adds per-app media routing, built-in Antigravity integration with custom app management, reference-image video generation, and automatic config/tool refresh.

- **Per-app routing & custom apps**: Added built-in Antigravity integration (auto-syncs `~/.gemini/config/mcp_config.json` on connect and startup) plus an "Add app" flow in Integrations for custom tool-connected apps with dedicated IDs, enable/disable toggles, and per-app stats. Per-app tier dialogs now include Image and Video ordering alongside Low/Mid/High tiers, overriding the global order when customized.
- **Reference-image video generation**: `generate_video` now accepts `image_paths`, `last_image_path`, `size`, and `out_dir`. Volcengine Ark automatically sends `first_frame`, `first_frame` + `last_frame`, or multi-image `reference_image` entries; Agnes supports first and last frames; OpenRouter and OpenAI-compatible providers forward reference images.
- **Live config & tool refresh**: `config.Store` hot-reloads external edits to `config.yaml` by mtime, and stdio MCP processes subscribe to backend events to refresh tool hints and emit `tools/list_changed` when media models change.
- **Fixes**: Passing `tier: "default"` no longer bypasses custom media ordering or smart dispatch, and specifying an unavailable tier (such as `best` without an OpenAI account) falls back to the user's ordered media list instead of invoking disabled models. Fixed a crash in the Models page when opening the tier dialog for media-only accounts (e.g. Ark) with no text models.
