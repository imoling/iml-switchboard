这一版把 0.4.x 里陆续改的东西收在一起：宿主识别更稳，Hermes 能整个接管，下载先走 Gitee。

**宿主**

- DeepSeek Harness：只装了桌面版、`dsh` 命令还没进 PATH 也认得出来，看的是它数据目录里自己建的 profiles、sessions 这些。
- Hermes Agent：接入后多一个「接管模型」开关，打开把它的主模型指到 Switchboard（型号 `router-auto`，走按量付费），原来的 model 段存在数据目录，关掉原样放回；重启 Hermes 生效。宿主页上它的标签改成「订阅 · 派活」，之前标错了。

**下载与更新**

- 「检查更新」和 `install-mac.sh` 都先查 Gitee 镜像，镜像没有再去 GitHub。
- Gitee 同步脚本：每个文件最多传 15 分钟、重试两次，超过 60 MB 的（AppImage）不再传 Gitee、只附 GitHub 地址；同步任务加 45 分钟上限。0.4.0 之后镜像落后，就是一次上传卡住把后面的同步全堵掉了。

**模型**

- 按量付费账号配好后能改密钥、接口地址和名字，先验证再存。

**自 0.4.0 以来的其它改动**（0.4.1 到 0.4.3）

- 分派表新增写作、自动化、记忆整理三类规则，没命中规则的请求按实际情况命名，不再统称「未归类」。
- 总览第二张卡改成「自动分档省下」，额度窗口移到模型页，记录表来源带宿主图标。
- 订阅渠道的版本号缓存十分钟，每个页面不再等半秒到一秒。

---

0.5.0 collects the 0.4.x follow-ups: DeepSeek Harness is detected from its data directory even when `dsh` is not on PATH yet; Hermes gets a "take over model" switch that points its main model at Switchboard and restores the original on toggle-off; update checks and the macOS install script try the Gitee mirror before GitHub; the Gitee sync has per-file timeouts, a 60 MB cap and a job time limit; pay-as-you-go accounts can change key, address and name after setup. Also included from 0.4.1–0.4.3: new writing / automation / housekeeping rules with named heuristic fallbacks, the overview savings card, quota windows on the Models page, and the cached CLI version probe that made every page open instantly.
