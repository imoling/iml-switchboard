这一版做了两件大事：让宿主自己的对话也能走 Switchboard（接管），以及把 WinWork、自建网关这类公司内部的模型服务接进来。其余是接入页和托盘的返工。

**接管宿主自己的对话**

- Claude Code、Claude Desktop、Codex 各有一个「接管模型」开关：打开后它们自己的对话改走 Switchboard 挑的按量付费模型，订阅暂停；关掉原样恢复。Claude Code 和 Codex 的 `/model` 里能选「自动分档」、三个档位或任何一个按量付费型号；Claude Desktop 的菜单里是这四档。
- Codex 的模型目录从本机 Codex 自带的目录克隆，Codex 升级后自动跟上；目录它读不了时自动撤掉，不会让它起不来。
- 工具调用、并行工具、工具返回的图片在两种协议之间都能来回转；Codex 桌面版里生成的图片直接显示在对话里。

**公司内部的模型服务**

- WinWork（讯飞）：装了就自动出现在「模型与账号」的订阅那组，标「不计费」，它网关里的 Sonnet、DeepSeek、Qwen、Kimi 等型号按档位参与调度。WinWork 没打开时有请求会在后台隐藏启动它，令牌每次从它的配置现读，不保存。接入页也能把 WinWork 内嵌的 Claude Code 接进来。
- 自定义服务：填任何一个 OpenAI 兼容地址和密钥，型号从服务拉，自己选图标；服务里的出图型号在媒体里能选。

**接入页**

- 模型列表：Codex（接管时）、WorkBuddy、pi、DeepSeek Harness、OpenClaw 的菜单里列哪些型号、谁排第一，在接入页的弹窗里勾选、排序，保存后立刻写进宿主的配置；没改过就跟着默认走，新加账号的型号自动进表。
- WorkBuddy 改为一键接入、断开，不再手动粘贴；pi、DeepSeek Harness、OpenClaw 只认装没装命令；豆包工作派过活就显示已接入。
- 宿主卡片重排，去掉了解释性文案。

**概览与实验功能**

- 概览最上面是全貌：左边接入的智能体，中间调度，右边渠道；每完成一次请求有一个光点从发起方走到干活的渠道。
- 实验功能里多了「刘海」：有请求时屏幕顶部的黑色缺口两侧亮起，发起方和模型提供方一来一回。默认关，在设置最下面。

**修了什么**

- 托盘弹窗第一次打开落在屏幕中间、每来一次请求就空白：已处理。
- macOS 上每次读密钥都弹「security 想要使用钥匙串中的机密信息」：旧条目第一次读到后换成不再弹框的写法。
- 没登录的 ChatGPT 订阅不再占一行；费用的小数不再拖一长串；WinWork 网关流式回包里工具调用串在一起的问题。
- 媒体：服务端说正忙时原地等一等再提交，提交没成功就没计费；回包的摘要去掉请求号。

**安装**

- macOS 可以用 `scripts/install-mac.sh`：下载本机芯片对应的最新 dmg（GitHub 连不上换 Gitee），装到「应用程序」，清掉下载来源标记，不用去「隐私与安全性」点「仍要打开」；后台服务没在干活时顺手换成新版本。
- 覆盖安装后到设置里点一下「重启」，让后台换成新版。安装包仍未签名。

Two big additions: hosts' own conversations can now go through Switchboard (takeover), and in-house model services such as WinWork gateways and custom OpenAI-compatible endpoints can be plugged in. The rest is a rework of the integrations page and the tray popover.

- Takeover: a switch each for Claude Code, Claude Desktop and Codex routes their own chats through the pay-as-you-go model Switchboard picks; `/model` in Claude Code and Codex lists auto, the three tiers and every pay-as-you-go model. Codex's model catalog is cloned from the local Codex and follows upgrades. Tool calls, parallel tools and tool-returned images convert both ways.
- In-house services: WinWork appears automatically as a no-charge account and is launched hidden on demand; custom services take any OpenAI-compatible base URL, pull their model list and can pick an icon.
- Integrations: a per-host model list (which models the host menu shows, in what order, which is default) for Codex, WorkBuddy, pi, DeepSeek Harness and OpenClaw; WorkBuddy connects with one click.
- Overview topology with live request animation; an optional notch animation under lab features.
- Fixes: tray popover placement and blanking, repeated macOS keychain prompts, signed-out ChatGPT rows, cost rounding, streamed tool calls from the WinWork gateway.
- Install: `scripts/install-mac.sh` downloads and installs the dmg without the Gatekeeper "open anyway" step. Installers remain unsigned; see the [README](https://github.com/imoling/iml-switchboard/blob/main/README.en.md#install).
