一个小改动：按量付费账号配好后能改了。

- 模型页每个按量付费账号的「操作」菜单多了「改密钥 / 地址」：密钥留空不改；自定义服务和 OpenRouter 可以改接口地址；自定义服务还能改名字。
- 保存前先用新值验证一次（自定义服务顺便把型号列表换新），没通过就不动旧的，填错不会把能用的账号弄坏。

---

One small addition: pay-as-you-go accounts can now be edited after setup. The account's action menu has "change key / address": leave the key blank to keep it; custom services and OpenRouter can change the endpoint; custom services can be renamed. The new values are verified before anything is saved, so a typo never breaks a working account.
