0.4.0 发出后紧接着的一版：把「未归类」说清楚，总览和模型页按反馈再调一次。

**分派**

- 任务表新增三类内置规则：写作（写一篇、文章、报告、讲稿、PPT、补充几页 → 中档）、自动化（Codex 定时任务这类以 Automation: 开头的请求 → 中档）、记忆整理（Codex 自己整理会话记忆的内部请求 → 低档）。老配置升级时自动补进来。
- 没命中任何规则的请求不再统称「未归类」，按实际情况记成「带工具的回合」「带代码」「长消息」「短消息」，总览的任务类型统计和记录表都照这个显示。

**总览与模型**

- 总览第二张卡改成「自动分档省下」，小字写明基线是全用 Opus 的价；订阅额度不再占总览。
- 模型页每个订阅卡片底下列出各额度窗口（本周、5 小时窗口、其中 Fable…），估算的标「估算」；「订阅」标题右侧可以刷新额度。
- 记录表的来源列带宿主图标。

A quick follow-up to 0.4.0: three new built-in task types (writing, automation, memory housekeeping) so Codex's scheduled runs and document-writing sessions stop showing as "unclassified"; heuristic fallbacks are now named by what they are (tool turn, code, long message, short message). The overview's second card shows savings from automatic tiering with its baseline stated; subscription quota windows moved to the Models page with a refresh button; the records table shows host icons.
