功能版：侧栏多了一页「彩蛋」，一张会动的像素画，演每一次请求里应用和模型怎么来回；第五套风格主题「魔法学院」。

**彩蛋**

- 放在侧栏「设置」下面。应用在左边，判档的在中间，模型按档位住在右边的楼里，出图出视频的在底下。来一单，信使把信送到中间；判档的把活交给某一层的模型；模型干完再回给应用。换人、改判、请应用跑工具、异步出视频、退回太长的请求、额度用完、评估，各有各的演法，画面下方的旁白一行一件事。
- 画面跟着风格主题换：标准是写字楼（投屏模式也是它），点将台是河边大营，魔法学院是湖边塔楼，后宫是宫城，海王是码头和海底。天气跟着状态变：刚有报错下雨，订阅额度紧张下雪（海王是起雾），晚上有月亮。
- 没活的时候模型互相搭话。每个型号有固定的性格：亲碳派喜欢人类，嘲碳派吐槽人类，再配一种脾气（嫌活杂、嘲牛马、佛系、卷王）；接到活、交差、失手、半夜还在派活、额度快见底都会嘀咕；每套主题还有自己的台词。
- 点一下模型它挥手说一句，卡片里看它住哪层、什么性格；「演示」是一段 70 秒的固定剧本，没接应用也能看；把模型拖到更高一层，就是把它最近那单记成判低了、请高一档重做。
- 窗口藏起来时不画，帧率封顶 30。

**魔法学院主题**

- 第五套风格主题，档位叫学徒、导师、教授、校长。原创的魔法学校，不用哈利波特的名字、人物和标志。

**后台**

- 事件流的 `call_start` 带上型号、档位、规则原本判的档、判官、任务类型、会话、是不是工具回合、第几个候选；新增 `bounce` 事件（请求太长被原样退回）；记录里带工具个数和「太长」标记。老界面不受影响。

0.7.0 adds a "彩蛋" page under Settings: an animated pixel-art scene that plays every request as a little story (a courier carries the letter in, the dispatcher picks a tier, a model does the work and sends the reply back; fallbacks, re-judging, tool round-trips, async video jobs, context bounces, exhausted quotas and evaluations each have their own staging). The scene follows the UI theme (office, army camp, magic academy, palace, seaside) and the weather follows state. Idle models chat with fixed personalities; clicking a model makes it talk, dragging it up a floor re-runs its last call one tier higher. A fifth theme, 魔法学院, joins the four existing ones. The event stream's `call_start` now carries model, tier, rule tier, judge, task type, session and attempt number, and a `bounce` event reports requests returned for being too long.
