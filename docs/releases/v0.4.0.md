这一版把界面重排了一遍，补上了「每档先试谁」的手排能力，菜单栏图标重画，并修掉几个会让请求整轮失败的问题。

**界面重排**

- 左侧菜单从八项缩到六项：总览、分派、模型、媒体、宿主、设置。「请求记录」并进总览，「评估」成为分派页的「回看」页签。
- 总览只留三个会影响动作的数字：按量花费（和本月上限）、订阅额度（只列用过的）、调度次数（订阅 / 按量 / 媒体占比）。拓扑图默认收起成一行「接入 N 个 · 渠道 M 个」，点开展开，开合记住。下面直接是记录表，带搜索、来源、渠道和「只看失败」。
- 记录表里任务用中文名，模型用显示名，订阅走的写「订阅」，免费型号写「免费」，失败的一行直接带原因。
- 宿主页改成左边列表、右边详情：列表分已接入、可接入、未安装，只有名字和状态点；详情里只说这个宿主在哪生效、什么时候生效，开关的副文案只写后果。规则导入导出从设置挪到分派页。
- 主窗口右半边的标题行和顶部留白也能拖动窗口。

**档位候选：每档先试谁**

- 分派页新增「档位候选」：低、中、高三档各一张表，勾选哪些渠道的型号进这一档、箭头排先后，第一个先试，保存立刻生效。
- 每个宿主可以在宿主页另排一张自己的表，只对它生效；没自己排的档跟全局，全局也没排的按内置规则。表里条目全失效时自动往下一层找。
- 订阅在哪能用说清楚了：宿主页每个宿主标「订阅 · 派活」「订阅 · 纯对话」或「不走订阅」，模型页订阅那组下面说明带工具的回合走按量付费，宿主型号表里「订阅优先」标「只接不带工具的对话」。

**菜单栏图标与标志**

- 菜单栏图标重画成实心底板挖空叉路，喂的是 2x 位图，Retina 上不再糊。设置的实验功能里可以在八种样式间切换：底板、线框、无框、插线板、拨杆、破框、像素主帅、三档。
- 修了模板图标记没生效的问题：以前图标一直是非模板的黑底图，菜单栏变深色或壁纸鲜艳时和别的图标不一致；现在跟着系统反白。后台重启后图标停在灰色的问题也修了。
- 主窗口左上角的标志换成和应用图标同一张。

**修了什么**

- 会话粘住的模型被限流或额度用完后，不再整轮报「没有可用的模型」，改为顺着这一档的候选回退，并清掉粘性记录。
- 只装了 ChatGPT 桌面版、没有单独装 `codex` 命令时，接入页和模型页不再说「未安装」：桌面版自带的那份命令会被找到，命令不在 PATH 上时登录提示写全路径。
- 宿主从没设过选项时接入页会白屏：已处理。
- 后台换了版本后界面的词表不再停留在旧版。

**安装**

- 覆盖安装后到设置里点一下「重启」让后台换成新版，后台有请求在跑时安装脚本不会打断它。安装包仍未签名。

This release reworks the interface, adds hand-ordered tier candidate tables (global and per host), redraws the menu bar icon, and fixes several ways a request could fail outright.

- Six menus instead of eight: Overview (now including the records table), Dispatch (rules plus the review tab), Models, Media, Hosts (a list-and-detail layout with trimmed copy) and Settings.
- Tier candidates: pick which channel models belong to each tier and in what order, globally or per host; stale entries fall through to the next layer.
- Menu bar icon: a solid tile with the fork cut out, shipped at 2x, with eight alternative styles under Settings → Lab; the template flag is now applied correctly so the icon follows the menu bar colour.
- Fixes: a sticky session no longer fails the whole request when its model is rate-limited; the Codex CLI bundled inside the ChatGPT desktop app is detected; the hosts page no longer crashes for hosts without saved options; theme words reload when the backend is replaced.
