Switchboard 的第一个公开版本：把订阅的模型、按量付费的模型、生图生视频模型统一管起来，让 Claude Code、Codex、WorkBuddy、Hermes 这些智能体在哪都能用，按难易自动挑模型，能省就省。

**这一版有什么**

- 订阅渠道：Claude（`claude -p`）、ChatGPT（`codex exec`）、Antigravity（`agy -p`），只启动未修改的官方命令行，不读登录信息；常驻时预热下一个进程，Claude 约 4 秒、Antigravity 约 5 秒出结果。
- 按量付费：智谱、百炼、DeepSeek、Moonshot、MiniMax、火山方舟、OpenRouter、Anthropic、Agnes AI、302.ai。
- 媒体：生图、生视频三档，动画在本机用 Remotion 渲染。
- 调度：低、中、高三档加顶配；规则拿不准时请低档模型判档；失败或额度用完自动换下一个模型；装不下时换窗口更大的模型。
- 接入：Claude Code、Codex CLI、Gemini CLI、Hermes、WorkBuddy、豆包工作、pi、OpenClaw、DeepSeek Harness。
- 菜单栏应用：额度、花费、近 7 天省下多少、路由规则、评估；费用可按人民币或美元显示。

**安装**

- macOS：下载 dmg（Apple 芯片选 aarch64，Intel 选 x64）。安装包未签名，首次打开请在「系统设置 → 隐私与安全性」里点「仍要打开」。
- Windows：下载 msi 或 exe。安装包未签名，SmartScreen 提示时点「更多信息 → 仍要运行」。
- 还需要至少一个已登录的官方命令行（`claude`、`codex` 或 `agy`），或一个按量付费账号。

**已知问题**

- Windows 版已完成移植并在 CI 上跑过全部测试，但还没有在真实的 Windows 电脑上手工用过，欢迎反馈。Linux 包能构建，未验证。
- 界面目前只有中文。

---

The first public release. Switchboard brings your subscription models, pay-as-you-go models and image and video models under one roof, makes them usable from every agent you run, and picks a model by difficulty to save where it can.

- Subscriptions are spent only through the unmodified official CLIs; Switchboard never reads sign-in data.
- Installers are unsigned: on macOS, allow the app under System Settings → Privacy & Security; on Windows, choose "More info → Run anyway" at the SmartScreen prompt.
- The Windows build passes the full test suite in CI but hasn't been used by hand on a real Windows machine yet. Linux packages build but are untested.
- The interface is in Chinese for now.

See the [README](https://github.com/imoling/iml-switchboard/blob/main/README.en.md) for details.
