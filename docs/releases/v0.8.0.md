功能版：每个模型服务可以单独调思考强度；对话里提到动画，照常交给文字模型。

**新功能**

- 思考强度：在「模型」页点卡片上的档位那一排，打开「各档位用谁」，最下面可以选默认、轻度、中度、深度。默认什么都不传，跟着服务自己的设置；调低更快更省，难题可能答得浅。设了以后卡片上会显示「思考 轻度」这样的标记。
- 能设思考强度的服务：Claude 订阅（官方命令行的 `--effort`）、ChatGPT 订阅（`model_reasoning_effort`）、OpenRouter、302.AI 和自定义服务。智谱、百炼、DeepSeek 这些服务写法各不相同，或者不认这个参数，暂时不显示这一项。
- 某个型号不认思考强度、上游因此报错时，Switchboard 去掉这个参数再发一次，请求不会因为这项设置失败。判档、判官这类内部小调用不带思考强度，速度不受影响。

**修复**

- 分档规则里去掉「动画」。以前对话里一出现「动画」「动效」「转场」「Remotion」，就会被判成要做动效视频、转去本机渲染，应用里正在进行的对话因此调不到终端的 claude、codex。现在这类说法按写代码交给中档文字模型；要做动效视频，照样点名调用 make_animation。
- 「做一段数据可视化动画，柱状图…」这类说法不再被当成出图。
- 老配置升级时自动摘掉「动画」这一行，规则版本升到 7；你自己建的、类型是动画的规则也不再自动生效。

**测试**

- 金标、盲测里做动画、动效的样本改标为中档（现在按写代码处理）。金标 108 条准确率 100%，盲测 60 条从 65.0% 升到 66.7%。
- 新增测试覆盖：老配置升级摘掉动画行、规则和判档员都不再自动认动画、点名 make_animation 仍做动效视频、思考强度按服务带上、claude 和 codex 的命令行参数、按量付费的两种写法和不认时去掉重发。

**说明**

- Claude 订阅的思考强度要较新的 claude 命令行（2.1.330 实测可用）；更老的版本不认 `--effort`，设了会报错，改回「默认」即可。

0.8.0 adds a per-service thinking effort setting. In Models → a card's tier row, choose Default, Light, Medium or Deep; Default sends nothing and follows the service. Supported: Claude subscription (`claude --effort`), ChatGPT subscription (`model_reasoning_effort`), OpenRouter (`reasoning.effort`), 302.AI and custom services (`reasoning_effort`). If an upstream model rejects the parameter, Switchboard retries once without it; internal classifier and judge calls never carry it. The built-in "Animation" routing rule is removed (rules version 7, dropped from old configs on upgrade): prompts mentioning animation, motion effects, transitions or Remotion now go to the mid-tier text model as coding work instead of being diverted to video rendering, which used to keep host conversations from reaching the terminal CLIs. Animation videos are still available by calling make_animation explicitly. Golden set stays at 100%; holdout goes from 65.0% to 66.7%. Older claude CLIs without `--effort` will error when an effort is set; switch back to Default.
